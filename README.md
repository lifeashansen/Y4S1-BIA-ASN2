## Prequisites

- uv
- python

### Replication Steps

- Clone this repo and cd into it
  `git clone https://github.com/lifeashansen/Y4S1-BIA-ASN2.git && cd Y4S1-BIA-ASN2`

- Sync all dependencies

  `uv sync`

- Run the program

  ` uv run src/main.py`
